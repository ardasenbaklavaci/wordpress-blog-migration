# Welcome to Your New Blog

This is an example post showing how to create blog content for your Next.js blog.

## Writing Markdown

You can use standard Markdown syntax:

### Headers

Use `#` for headers:
- `# H1 Header`
- `## H2 Header`
- `### H3 Header`

### Text Formatting

- **Bold text** using `**text**`
- *Italic text* using `*text*`
- ~~Strikethrough~~ using `~~text~~`

### Lists

Unordered lists:
- Item 1
- Item 2
- Item 3

Ordered lists:
1. First item
2. Second item
3. Third item

### Code

Inline code uses backticks: `const x = 5;`

Code blocks:
\`\`\`javascript
function helloWorld() {
  console.log("Hello, World!");
}
\`\`\`

### Links and Images

[Click here](https://example.com) for a link

```markdown
![Alt text](/images/image.jpg)
```

### Blockquotes

> This is a blockquote. It's perfect for highlighting important information.

## Front Matter

Each post has front matter at the top in YAML format:

```yaml
---
title: "Post Title"
date: "2025-01-10"
excerpt: "Short description"
categories: ["Category1", "Category2"]
author: "Your Name"
image: "/images/image.jpg"
---
```

**Fields:**
- `title`: Post title (required)
- `date`: Publication date in YYYY-MM-DD format (required)
- `excerpt`: Short preview text (optional)
- `categories`: Array of categories (optional)
- `author`: Author name (optional)
- `image`: Cover image path (optional)

## Tips for Gaming Blog Content

When writing gaming and hardware posts include specific details like game names, FPS benchmarks, and hardware specifications.

Happy blogging! 🎮
